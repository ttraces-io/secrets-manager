traces-sm — Rust-native SGX secrets and key management framework

traces-sm is an open-source key and secret management framework that runs its cryptographic operations inside an Intel SGX enclave, written entirely in Rust on Fortanix EDP.

Hardware-Enforced Security Features

Engineered to isolate secrets from compromised host operating systems and hypervisors.

EPC

Intel SGX EPC Isolation

All decryption, key generation, signing, and zeroization operations execute strictly within hardware-encrypted Enclave Page Cache (EPC) RAM using Fortanix EDP. Read how we design this in our guide to building Intel SGX enclaves in pure Rust.

NIST

NIST SP 800-57 Lifecycle

Enforces a 4-phase key lifecycle state machine (PreOperational, Operational, Deactivated, Destroyed) with cryptoperiod tracking. Learn more on our FIPS 140-3 alignment overview.

ZERO

Volatile Memory Zeroization

Private key byte vectors wrap in zeroize::Zeroizing<T>, forcing compiler intrinsics to overwrite RAM registers on drop. Read our detailed guide on how traces-sm zeroizes secrets in Rust.

The untrusted host proxy cannot inspect memory inside the Enclave Page Cache. Inter-node communications are protected via RA-TLS attestation quotes embedded in X.509 certificates.

Hardware Isolation vs Software Vaults

Traditional secret managers process plaintext in host RAM. traces-sm isolates all decryption inside an Intel SGX enclave.

HashiCorp Vault and OpenBao store encrypted data at rest, but unpack secrets into standard OS RAM during operations. If a root hypervisor or OS is compromised, memory inspection tools can extract private keys. traces-sm keeps all operational keys strictly inside SGX hardware memory.

In-Enclave Cryptographic Capabilities

Verified status of key algorithms implemented in enclave source code.

RSA & ECDSA

✓ Implemented

RSA-2048, RSA-4096 (OAEP), ECDSA P-256, P-384, P-521, Secp256k1 implemented via ring and rsa crates.

ZK Proofs & SSS

⚠️ Partial

Schnorr PoK and Bulletproofs implemented via schnorrkel and bulletproofs. Shamir SSS implemented; VSS commitment check stubbed.

Post-Quantum (PQC)

⛔ Not implemented

PQC functions in enclave/src/pqc.rs are currently stubs returning dummy vectors or true. Read our PQC status roadmap.
